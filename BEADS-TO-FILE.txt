Recommended new beads (none mandatory; substrate fix landed cleanly):

(none surfaced during the substrate fix — `mul`, `sqrt`, and `powInt` do
not have the same precision-floor pattern as `div`.

`mul`: result mantissa bit-length = a.mant.bitLength + b.mant.bitLength,
which is always ≥ max(a.bits, b.bits). normalise then truncates back to
prec bits. No information lost prior to truncation, so no precision-floor
analogue.

`sqrt`: the algorithm explicitly shifts the working mantissa to
2*prec + safety bits before isqrt, regardless of input bit-length, so
the precision is set by the user's prec parameter alone.

`powInt`: built on `mul` and `div`; with the post-djp `div`, powInt
inherits the lift correctly.

If a follow-up agent finds a substrate quirk in `add` or `sub` (the
align-and-add path; the alignment shift could in principle lose bits if
one operand's exponent is far smaller than the other's *and* the
precision attribute is small), it should be filed as a separate bead
with a worked example.)
