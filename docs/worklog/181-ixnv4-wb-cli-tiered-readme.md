# 181 — `wb` discovery CLI + tiered progressive-discovery README (ixnv.4)

**Issue:** `scientist-workbench-ixnv.4` (child of epic
`scientist-workbench-ixnv` — registry as the single source of truth).
**ADR:** `docs/adr/0043-registry-single-source-of-truth.md`.
**Date:** 2026-05-21.

## Context

`README.md` was a 401-line file an agent had to read top to bottom before
its first tool call. The discovery infrastructure already existed —
`registry-list`, `registry-search`, every tool's `--schema` / `--examples`
/ `--invariants` / `--help` — but had no single entry point and was not
even mentioned until two-thirds of the way down the README. The keystone
sibling `ixnv.2` had already turned the catalog into a generated table (in
a marked region *inside* `README.md`); `ixnv.3` made the goldens generated.
`ixnv.4` is the progressive-discovery model: a `wb` CLI that fronts the
registry, and a README collapsed to a Tier-0 bootstrap.

ADR-0043's binding constraint: every generator and CLI reads the **live
registry** (a `tools/` walk + `importToolDef`), never a static list. A `wb`
that read a hand-maintained tool list would be a *new* drift surface — the
exact thing the epic exists to remove.

## What changed

**New `wb` discovery CLI — `wb.ts` at the repo root.** A literate CLI
script (not a value-protocol tool: no seven-artefact contract, no `def`).
Chosen invocation: **`bun wb.ts`** — a root file is the shortest thing that
makes `bun wb.ts` work directly; a `"wb": "bun wb.ts"` script in
`package.json` also gives `bun run wb`. Subcommands:

- `wb` (no args) — Tier 1: walks the live registry, prints every tool's
  `name` + one-line `def.summary`, with a footer naming every other
  subcommand.
- `wb <tool>` — Tier 2: `describeTool` gives decoded `Schema`s + wire-form
  `examples` / `invariants`; the CLI renders the schema with a compact
  one-line structural form, each example as its canonical input bytes (a
  copy-pasteable invocation fragment), and surfaces the determinism tier.
- `wb search [--consumes/--produces/--head/--name]` — Tier 2: builds the
  `registry-search` tool's input record from friendly flags and calls that
  tool's `def.fn` **in-process** — it reuses discovery, does not
  reimplement it.
- `wb protocol` / `wb contract` — Tier 3: stream the relocated reference
  docs to stdout.
- `wb help` / `-h` — usage.

Unknown subcommands and unknown tool names fail loud (Rule 1) with a
Levenshtein "did you mean…" suggestion against the live registry.

**Tiered README.** `README.md` collapsed 401 → 66 lines: what a tool is
(one JSON value in, one out), the one hard fact before a first call
(numerics are strings, no raw JSON numbers, no `null`), and the first
command — `bun wb.ts`. Everything else is a pointer.

**Relocated content (no information lost).** Every author-facing section
moved into `docs/` files reachable via `wb`:

| Old `README.md` section | New home |
|---|---|
| The value protocol | `docs/protocol.md` |
| Tool invocation | `docs/protocol.md` |
| Standard flags | `docs/protocol.md` |
| The schema language | `docs/protocol.md` |

**Catalog relocation — `gen-catalog.ts` + `check.ts` updated in lockstep.**
The catalog moved out of `README.md` (which is now tiny) into its own
generated file `docs/CATALOG.md`. `scripts/gen-catalog.ts` was rewritten:
instead of splicing a table into a marker region inside `README.md`, it now
emits the whole `docs/CATALOG.md` file with the `AUTOGENERATED` banner as
the file header. The `check.ts` drift phase (renamed "codegen: tool
catalog") was updated **in the same change** to byte-compare
`docs/CATALOG.md` — if only the generator had moved, the drift phase would
have byte-compared a stale `README.md` target and the build would have
broken. Verified: the phase passes.

`CLAUDE.md` Law 2 was updated — the "catalog row in `README.md`" and "a row
in the main README's File layout" bullets now point at the generated
`docs/CATALOG.md` (do not hand-edit) and `docs/repo-map.md`.

## Why these choices

**`bun wb.ts`, root file.** The task asked for the most ergonomic
invocation. A root `wb.ts` makes `bun wb.ts` work with zero indirection;
the `package.json` `wb` script is a convenience alias. A `bin` entry was
rejected — this is a dev-repo CLI, not a published package.

**`wb` calls `registry-search.def.fn` in-process, not as a subprocess.**
ADR-0010 makes tool modules side-effect-free on import; `wb.ts` already
imports `@workbench/contract` registry helpers, so importing one tool's
`def` and invoking its `fn` is the same in-process discipline `registry-*`
already follow. No spawn, no double schema-validation.

**Schema rendered, not dumped.** `--schema` emits the verbose wire
encoding; unreadable in a terminal. `describeTool` returns a *decoded*
`Schema`, so `wb <tool>` walks the `SchemaNode` tree to a terse one-liner
(`record{ base: integer, … }`) — a display rendering, never parsed back.

**Whole-file generated catalog, not a marker region.** `docs/CATALOG.md`
is now a fully generated file, so the banner is the file header and
regeneration overwrites wholesale — no marker-pair bookkeeping.

## Frictions surfaced

- The Tier-0 README landed at 66 lines, above the ~30-40 target. The
  overrun is the Pointers block: dropping it would *lose* the trail to the
  relocated docs, violating the "don't lose information" constraint. Kept
  it — a pointer list is not bootstrap weight an agent must read to make a
  first call; it skims it.
- "File layout" and "What this is *not*" had no natural home in
  `protocol.md` or `contract.md`. Rather than delete them (constraint:
  lose nothing) a third file `docs/repo-map.md` was created for the
  layout, the snap-Bun install corner, and the scope boundary.
- ADRs referencing "the README catalog" were left untouched — ADRs are
  frozen snapshots (Rule 3); only the *live* law (`CLAUDE.md`) was updated.

## Acceptance

- `bun wb.ts` lists all 55 tools from the live registry; `bun wb.ts
  mod-pow` shows schema + 12 examples + 5 invariants + the symbolic tier;
  `bun wb.ts hypergeometric-pfq` correctly shows the `arbprec` tier.
- `bun wb.ts search --consumes string` → 22 matches; `--produces integer`
  → 40; no-filter `search` fails loud; `wb --foo` and `wb mod-poww` fail
  loud with suggestions.
- `bun wb.ts protocol` / `contract` stream the relocated docs.
- `README.md` is 66 lines (was 401); every removed section relocated.
- `gen-catalog.ts` emits `docs/CATALOG.md`; the `check.ts` "codegen: tool
  catalog" drift phase byte-compares it and passes.
- `bun run check` — see the close note for the verbatim result.
